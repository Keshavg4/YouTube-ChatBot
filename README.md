# 🎥 YouTube Transcript Q&A Chatbot (Agentic RAG)

An **Agent-based Retrieval Augmented Generation (RAG) system** that allows users to ask questions from **YouTube video transcripts** and get **accurate, context-grounded answers** using **LangGraph, FAISS, Groq LLM, and Streamlit UI**.

---

## 🚀 Features

- 🔍 Question answering from YouTube videos  
- 🧠 Agentic RAG pipeline using **LangGraph**  
- ⚡ Fast inference with **Groq LLM**  
- 📚 Semantic search using **FAISS + HuggingFace embeddings**  
- 💻 Clean UI using **Streamlit**  

---

## 🧠 Agent Use Case & Flow

### Use Case  
Enable users to instantly extract insights from long YouTube videos using **AI-powered question answering**.

### Flow  

User Query → LangGraph Agent → Transcript Retrieval → LLM → Answer
